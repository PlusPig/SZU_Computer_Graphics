# 🎨 深圳大学计算机图形学实验

本仓库包含 **深圳大学（SZU）计算机图形学课程** 的全部实验内容，  
实验代码适用于 **Visual Studio Code（VS Code）** 环境运行与调试。

---

## 实验内容说明

- 覆盖课程中主要的计算机图形学实验
- 包括基础绘制、几何变换、图形算法、图形管线等相关内容
- 每个实验以**独立文件夹**形式组织，结构清晰，便于查阅与维护

---

## 运行环境

- 操作系统：Windows / Linux / macOS  
- 编辑器：**Visual Studio Code**
- 编译环境：
  - C / C++（推荐使用 `g++` / `clang`）
  - OpenGL / GLFW / GLAD（如实验需要）

> ⚠️ 不同实验可能依赖不同库，请参考各实验文件夹内的说明。
